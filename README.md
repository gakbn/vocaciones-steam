# 🚀 Vocaciones STEAM
> **Descubre tu talento. Define tu futuro.**

Vocaciones STEAM es un sistema inteligente de orientación vocacional diseñado para guiar a jóvenes en la elección de su carrera universitaria dentro de las disciplinas de Ciencia, Tecnología, Ingeniería, Arte y Matemáticas. 

Esta iniciativa combina inteligencia artificial, psicología vocacional y tecnología de vanguardia. El sistema integra un test psicométrico procesado por inteligencia artificial para generar perfiles vocacionales personalizados y recomendar instituciones de educación superior afines al perfil del estudiante.

## ✨ Características Principales
* **🧠 Diagnóstico Inteligente:** Uso de un Árbol de Decisión (CART) para clasificar perfiles vocacionales de manera offline.
* **🤖 Análisis Profundo:** Integración con la API de OpenAI para generar una recomendación narrativa personalizada basada en las respuestas del test.
* **📍 Geolocalización:** Muestra universidades cercanas que ofertan las carreras sugeridas, optimizando la búsqueda de opciones académicas.
* **⚡ Accesibilidad Offline-First:** Diseñada como una Aplicación Web Progresiva (PWA) con Service Workers para garantizar el acceso en zonas con conectividad limitada.

## 🛠️ Stack Tecnológico
El proyecto implementa un Patrón de Arquitectura en Capas (Layered Architecture).
* **Frontend UI:** Angular v17.x estructurado como PWA para alto rendimiento.
* **Backend API:** NestJS v10.x sobre Node.js v20.x, garantizando código limpio y escalabilidad.
* **Base de Datos:** PostgreSQL v16.x gestionada mediante TypeORM para consultas geoespaciales.
* **Inteligencia Artificial:** OpenAI API y Firebase ML.
